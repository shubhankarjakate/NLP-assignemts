 Natural Language Processing (NLP) Assignments

A collection of Natural Language Processing assignments implemented using Python and modern NLP libraries.  
This repository covers fundamental and advanced NLP concepts including tokenization, stemming, lemmatization, vectorization, embeddings, transformers, sentiment analysis, and language modeling.



 📚 Course Overview

This repository contains practical NLP assignments focused on:

- Text Preprocessing
- Tokenization Techniques
- Stemming & Lemmatization
- Bag of Words & TF-IDF
- Word Embeddings
- Transformer Architecture
- Morphological Analysis
- Sentiment Analysis
- N-Gram Language Models
- Auto-complete Systems
